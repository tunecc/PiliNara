# PiliNara fork 差异说明

## 用户可见差异

- 播放器双击区域可自定义：左侧快退、中间播放/暂停、右侧快进，左右区域可在设置页拖动调整比例；调整页模拟真实播放状态——竖屏预览呈现半屏播放的视频区域，横屏预览会像全屏播放器一样旋转手机、预览铺满全屏。
- 左侧双击快退和右侧双击快进可分别设置时长。
- 新增“双指轻点暂停/播放”开关，两指短按屏幕可切换播放状态。
- 支持为指定 UP 主设置专属默认开播倍速：在「倍速设置」中管理名单，支持昵称搜索 / UID 添加；播放页右上角「更多设置」可为当前作者快捷添加 / 更换 / 移除专属倍速并立即生效；未指定作者仍使用全局默认倍速，播放中手动改速仅本次有效。
- “我的”页面提供可配置的横向预览卡片（上游 2.1.6 版本）：在「设置 → 外观设置 → 我的页卡片」中可选择显示与排序：我的收藏 / 观看记录 / 稍后再看 / 我的订阅；每张卡片显示对应内容的数量，横向滑动预览，滑到最后一张会自动加载更多，点击卡片标题进入对应页面。
- 稍后再看页面的单个移除操作改为直接移除，不再弹出二次确认。
- 用户空间视频列表支持客户端本地过滤（时长、播放量），可在筛选面板开启；开启过滤后若结果填不满一屏会自动翻页补足（有上限防刷接口，手动上拉可继续）。
- 应用内源码地址、问题反馈入口和检查更新地址切换到 `tunecc/PiliNara`。
- 支持屏蔽指定画质：在「音视频设置」中勾选要跳过的画质（如「1080P 高码率」），播放自动选档与播放器画质菜单都会剔除它；该档本会被选中时自动降一档（如改选「1080P 高清」），下载不受影响。
- 新增「Thread Ripper（多 CDN 并发下载）」开关（「音视频设置」内，默认关闭）：开启后播放器经本地代理取流，视频分片切小块并同时从多个 CDN 节点并发下载、逐段校验组装后再交给播放器，可提升起播与缓冲速度；内置屏蔽 P2P/PCDN 边缘节点与 Akamai 兼容处理，兼容 4K/杜比等高码率场景；预取按播放消费驱动（不会全速预取整个文件），PCDN 地址默认排除（可在设置中关闭排除）；开启期间「CDN 设置」选定的节点不参与选点（全部节点按速度自动竞速），关闭后该设置恢复生效。注意：并发下载会增加流量消耗，对直播不生效。

## 构建与依赖差异

- Flutter 版本固定为 3.47.0（`.fvmrc`，用 [fvm](https://fvm.app) 管理），不跟随上游升级；`environment.flutter` 与 `.fvmrc` 需保持一致。
- 三个依赖钉死兼容版本（iOS 构建约束，勿随上游升级）：`connectivity_plus: 7.0.0`、`device_info_plus: 13.0.0`、`file_picker: 12.0.0-beta.7`（上游新代码按 13.x API 编写时需在调用方适配回 beta.7）。
- iOS 本机构建：见 [BUILD_IOS.md](BUILD_IOS.md)；`lib/scripts/patch.sh ios` 一键应用全部补丁（含 SDK / material_ui / cupertino_ui / geetest 隔离），构建前必须先跑。
- 自动同步：`.github/workflows/sync_upstream_build.yml` 每日定时检查上游，有新提交时自动合并、构建 Android/iOS 并发布 Release；fork 只维护这一条 workflow 链（`android_reusable.yml`、`ios.yml` 为其被调用方）。

上游 PiliNara 的完整特性列表见上游 README。
