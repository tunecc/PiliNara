# 目标

把「双击区域调整」页的 横屏 / 竖屏 预览从"画一个不同宽高比的色带画布"升级为**模拟真实播放状态**：

1. **横屏预览**：切换后手机真实旋转为横屏（复用播放器全屏的旋转与沉浸机制），预览区域铺满整个屏幕，观感与真实的横屏全屏播放器一致，可在全屏宽度上拖拽分隔线调整区域。
2. **竖屏预览**：模拟真实的竖屏半屏播放状态——页面顶部为 16:9 的黑色视频区（双击区域所在处），视频区下方呈现模拟的视频页内容，与日常竖屏看视频的画面一致。

# 范围

- `lib/pages/setting/pages/double_tap_seek_zone_setting.dart` 重构预览形态：
  - **竖屏预览（默认）**：页面顶部为宽度撑满、16:9 的黑色视频区；视频区内保留三区色带、可拖拽分隔线、中央播放图标、左右「快退/快进 X 秒」动作提示；视频区下方用占位内容模拟真实视频页（标题、作者行、灰色占位块等，纯装饰不承载功能）；拖拽提示与百分比 chip 面板保留在页面下方。
  - **横屏预览**：移动端调用与播放器全屏相同的机制真实旋转设备——`hideSystemBar()` + 横屏模式（复用 `lib/plugin/pl_player/utils/fullscreen.dart` 的 `landscapeLeftMode()` / `landscapeRightMode()`），页面切换为全屏沉浸布局：三区铺满整屏、分隔线可拖拽，顶部悬浮精简操作（返回竖屏 / 重置 / 保存），底部悬浮百分比提示；桌面端不调用旋转，仅以全屏宽度画布呈现。
  - **状态恢复**：切回竖屏预览或离开页面（含系统返回键）时，恢复系统栏（`showSystemBar()`）与屏幕方向（`Pref.horizontalScreen` 为真则 `fullMode()`，否则 `portraitUpMode()`，与播放器 `resetScreenRotation` 语义一致）。
  - 两模式继续共用同一份 `doubleTapBackwardZone` / `doubleTapForwardZone` 配置，拖拽约束与保存 / 重置逻辑不变。
- `README.md`：更新双击区域条目措辞（横屏预览会真实旋转手机模拟全屏播放器，竖屏预览模拟半屏播放状态）。

# 非目标

- 不改动播放器本体、`DoubleTapSeekLayout` 算法、双击时长设置与作者专属倍速功能。
- 不在预览中实现真实视频播放、弹幕或控制栏交互（占位内容纯视觉）。
- 不做按方向独立的区域配置（维持共用一套）。
- 预览不自动跟随物理横竖屏（仅在模式切换时主动旋转；恢复交回系统/播放器逻辑）。

# 验收示例

- A1：在竖屏预览下进入页面，预览模拟真实半屏播放：顶部为 16:9 黑色视频区（含三区色带、分隔线、中央播放图标、快退/快进秒数提示），下方为模拟视频页内容；拖拽分隔线在视频区内生效，百分比实时更新并遵守约束。
- A2：切换到「横屏预览」后，手机真实旋转为横屏（移动端系统栏隐藏），三区铺满整个屏幕，可全屏宽度拖拽分隔线；顶部悬浮操作与底部百分比提示可正常交互。
- A3：横屏预览下切回「竖屏预览」，或在该状态下直接按返回键离开页面，屏幕方向与系统栏均正确恢复，无横屏残留；恢复正常后页面功能不受影响。
- A4：两种模式调整的是同一份配置：竖屏预览调整后切到横屏预览，分隔线位置同步；保存后播放器双击按配置生效（回归上一 change 的 A2/A4 语义）。
- A5：恢复默认仍为 25% / 50% / 25%；保存 / 重置 / 返回流程不回归。
- A6：桌面端进入横屏预览不调用设备旋转（不报错、不闪屏），以全屏宽度画布呈现并可拖拽。

# 约束与不变量

- 旋转与系统栏控制必须复用 `lib/plugin/pl_player/utils/fullscreen.dart` 既有工具，不重复实现；页面离开时必须恢复，不得影响播放器与其他页面的方向状态。
- 预览拖拽仍走 `clampBackward/ForwardPercentDouble`，约束与实际判定一致（左右 1%~40%、中间 ≥20%）。
- 现有单元测试与 `flutter analyze` 保持通过，不新增告警（全仓存量告警以改动文件定向 analyze 为准）。

# 决策

- 用户反馈定性：现有实现"只是模拟着横一下竖"，不符合真实播放状态；本 change 将横屏预览升级为真实设备旋转 + 全屏沉浸（与全屏播放器一致），竖屏预览升级为模拟半屏播放（16:9 视频区在页面顶部）。
- 横屏方向选择与播放器 `changeOrientation` 默认一致：Android 默认 `landscapeLeftMode()`，iOS 默认 `landscapeRightMode()`；桌面端跳过旋转。
- 恢复语义复用 `resetScreenRotation` 的判定：`Pref.horizontalScreen ? fullMode() : portraitUpMode()`；系统栏恢复用 `showSystemBar()`。
- 竖屏预览的模拟视频页内容为纯静态占位（标题行、作者行、灰块），不引入真实数据依赖。
- 竖屏预览仍是进入页面的默认模式。
