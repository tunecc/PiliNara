# 目标

两个相互独立的需求：

1. **双击区域调整页支持横竖屏模仿预览**：播放器设置 →「双击区域调整」页面增加 横屏 / 竖屏 模式切换。横屏模式以横屏播放器的画布形态（宽幅、黑底）完全模仿横屏播放器的双击区域布局；竖屏模式以竖屏播放页的画布形态模仿竖屏下的区域布局。两种模式下都可以拖拽左右分隔线调整「快退 / 播放暂停 / 快进」三个区域的宽度，让用户在与实际播放形态一致的预览里调整。
2. **播放页「更多设置」支持为当前作者快捷添加专属倍速**：视频播放页右上角「更多设置」面板新增「为当前作者添加专属倍速」入口，复用已有的作者专属倍速能力，就地选择倍速并保存后立即对当前视频生效，无需到设置页手动搜索作者。

# 范围

## 功能一：双击区域调整页

- `lib/pages/setting/pages/double_tap_seek_zone_setting.dart`：增加 横屏 / 竖屏 预览模式切换；两种模式下预览画布分别模仿横屏播放器与竖屏播放页的画布形态，保留现有的拖拽分隔线交互与百分比约束（左右各 1%~40%，中间保底 20%，由 `DoubleTapSeekLayout` clamp 逻辑保证）。
- 播放器手势判定接通：`lib/plugin/pl_player/view/view.dart` 的 `onDoubleTapDownMobile` 当前硬编码 `maxWidth / 4`（25% / 50% / 50%），用户配置的区域从未生效；改为使用 `plPlayerController.doubleTapSeekLayout` 判定 `DoubleTapType.left / center / right`。
- 设置项副标题（`lib/pages/setting/models/play_settings.dart` 的「双击区域调整」条目）保持按当前配置展示百分比（配置结构不变，无需改动存储）。

## 功能二：更多设置的作者专属倍速入口

- `lib/pages/video/widgets/header_control.dart` 的 `showSettingSheet()` 面板新增条目，位置放在播放行为相关分组中；subtitle 展示当前作者名与是否已设置专属倍速。
- 就地弹出倍速选择弹窗（复用 `Pref.speedList` 与 `play_speed_set.dart` 中 ChoiceChip 选倍速的交互样式）；保存调用 `Pref.upsertAuthorPlaySpeed`（或等价写入），随后调用 `applyAuthorDefaultSpeed(mid, force: true)` 立即对当前视频生效。
- 已设置专属倍速的作者再次打开时展示当前倍速，并提供移除入口（移除后回退全局默认倍速）。
- 非 UGC 内容（番剧/影视无 `owner`、本地文件）没有作者概念：不显示该条目。

# 非目标

- 不改动上下滑动手势（亮度/音量）的区域划分逻辑（`view.dart` 另一处硬编码 `maxWidth / 3` 属于另一功能，保持现状）。
- 不改动 `DoubleTapSeekLayout` 的边界约束语义（minSidePercent=1、maxSidePercent=40、minCenterPercent=20）与 normalize/clamp 算法。
- 不改动双击快进/快退的时长设置（5/10/15/20/30 秒选项）本身。
- 不改动作者专属倍速的存储结构与播放器自动应用逻辑（`applyAuthorDefaultSpeed` 等已存在能力按现状复用）。
- 不做「按作者管理列表」的新页面；管理仍走现有 倍速设置页 的作者专属倍速区块。
- 直播（`isLive`）与控制栏锁定状态下的双击行为保持现状（直接忽略）。

# 验收示例

功能一：

- A1：进入「双击区域调整」页，可切换 横屏 / 竖屏 预览模式；横屏预览呈横屏播放器画布形态（宽幅黑底），竖屏预览呈竖屏播放页画布形态（竖幅）；默认进入竖屏模式。
- A2：两种模式下均可拖拽左右分隔线调整区域宽度，拖拽过程中百分比实时更新，且遵守 1%~40%（左右）与中间 ≥20% 的约束；任一模式下的调整保存后另一模式的预览同步反映同一份配置。
- A3：预览画布包含中央播放/暂停图标与左右区域的双击动作提示（快退/快进图标 + 当前配置的秒数）；修改快进/快退时长设置后，提示中的秒数随之变化。
- A4：保存后双击播放器按配置区域实际触发：例如左区设为 10% 时，双击画布左侧 10% 以内为快退、中间为播放暂停、右侧对应区域为快进；重启 App 后配置保留。
- A5：恢复默认操作可将区域重置为 25% / 50% / 25%（现状能力保留）。
- A6：直播播放与控制栏锁定状态下双击行为不变（忽略）。

功能二：

- A7：播放 UGC 视频时，「更多设置」面板出现作者倍速入口，subtitle 显示作者名与设置状态（未设置 / 已设置 X.Xx）。
- A8：点击入口就地弹出倍速选择弹窗，选择并保存后：作者倍速存储新增该作者记录，当前播放立即应用该倍速，面板关闭。
- A9：已设置专属倍速的作者再次打开入口，可看到当前倍速并可就地更换或移除；移除后当前播放回退全局默认倍速，存储中该作者记录删除。
- A10：播放番剧/影视（无作者）或本地文件时，不显示该入口。
- A11：在倍速设置页的作者专属倍速列表中可以看到通过快捷入口添加/修改/删除的结果（同一存储，双向一致）。

# 约束与不变量

- 现有单元测试与 `flutter analyze` 保持通过，不引入新增告警（注意：仓库存在既有 analyze 告警，验收以「不新增」为准）。
- 双击区域拖拽约束（1%~40%、中间 ≥20%）在预览页与实际判定两侧保持一致。
- 作者倍速快捷入口的写入必须与 倍速设置页 读写同一存储（Hive `video` box 的 `authorPlaySpeeds`），保证两处一致。
- 面板既有条目与顺序不因新增条目改变行为。

# 决策

- **区域配置结构（Q1，用户已确认）**：横竖屏共用一套 `doubleTapBackwardZone` / `doubleTapForwardZone` 百分比，不新增配置结构、不做迁移；横屏 / 竖屏预览模式只是同一份配置在不同画布形态下的可视化，任一模式下调整都写同一份值。
- **接通播放器配置（Q2，用户已确认）**：本 change 一并修复 `onDoubleTapDownMobile` 的硬编码，改为 `plPlayerController.doubleTapSeekLayout` 判定 left / center / right；直播与控制栏锁定时忽略双击的现状保持。
- **预览还原程度（Q3，用户已确认）**：高还原——横屏预览为宽幅（约 16:9）黑底画布、竖屏预览为竖屏（约 9:16）画布；画布中央显示播放/暂停图标，左右区域显示双击动作提示（图标 + 「快退 X 秒 / 快进 X 秒」，X 取当前 `doubleTapBackwardDuration` / `doubleTapForwardDuration` 配置）；保留拖拽分隔线与百分比 chip 显示。
- **更多设置入口形态（Q4，用户已确认）**：就地弹出倍速选择弹窗（ChoiceChip 样式，选项来自 `Pref.speedList`），保存后立即对当前视频生效（`applyAuthorDefaultSpeed(mid, force: true)`）；已设置的作者展示当前倍速并可就地更换或移除；无作者内容（番剧/影视/本地文件）隐藏条目。
- 入口放置在 `showSettingSheet()` 播放行为相关分组（「重载视频」附近），不打乱既有条目顺序。
- 预览模式切换的默认方向：进入页面默认竖屏（更接近手机日常浏览形态）；切换状态不持久化，仅页面内生效。
